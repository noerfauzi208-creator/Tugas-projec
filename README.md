# To Do List App Interaktif

## 1. Deskripsi Proyek
To Do List App Interaktif merupakan aplikasi berbasis web yang digunakan untuk mencatat dan mengelola daftar tugas harian. Aplikasi ini dibangun menggunakan HTML, CSS, dan JavaScript dengan konsep manipulasi DOM. Pengguna dapat menambahkan, menandai selesai, dan menghapus tugas secara langsung tanpa memuat ulang halaman.

---

## 2. Tujuan Pembuatan
- Menerapkan konsep dasar HTML sebagai struktur halaman
- Menggunakan CSS untuk tampilan sederhana dan rapi
- Mengimplementasikan JavaScript untuk interaksi pengguna
- Melatih penggunaan DOM (Document Object Model)
- Mengelola logika program secara dinamis

---

## 3. Fitur Aplikasi
- Menambahkan tugas melalui input
- Validasi input agar tidak kosong
- Menampilkan daftar tugas secara dinamis
- Menandai tugas sebagai selesai
- Menghapus tugas
- Menghitung jumlah total tugas
- Menghitung jumlah tugas selesai

---

## 4. Alur Logika Aplikasi
1. Halaman To Do List ditampilkan
2. Pengguna memasukkan teks tugas
3. Pengguna menekan tombol "Tambah"
4. JavaScript memvalidasi input
5. Jika valid, tugas ditambahkan ke daftar
6. Pengguna dapat:
   - Menandai tugas sebagai selesai
   - Menghapus tugas dari daftar
7. Jumlah total dan selesai diperbarui otomatis

---

## 5. Algoritme Program
1. Inisialisasi variabel total dan selesai
2. Ambil nilai input dari pengguna
3. Jika input kosong, tampilkan peringatan
4. Buat elemen list (`<li>`) baru menggunakan DOM
5. Tambahkan tombol "Selesai" dan "Hapus"
6. Perbarui counter total dan selesai
7. Tampilkan perubahan secara real-time

---

## 6. Teknologi yang Digunakan
- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)

---

## 7. Cara Menjalankan Aplikasi
1. Buka folder project To Do List
2. Jalankan file `index.html` menggunakan browser
3. Aplikasi siap digunakan

---

## 8. Penyimpanan Data
Aplikasi ini belum menggunakan database.
Data tugas hanya disimpan selama halaman aktif (tidak permanen).

---

## 9. Kesimpulan
To Do List App Interaktif ini menunjukkan penerapan JavaScript DOM untuk membuat aplikasi web sederhana yang interaktif, dinamis, dan mudah digunakan.

Project ini dibuat sebagai latihan dan tugas mata kuliah Pemrograman Web.
